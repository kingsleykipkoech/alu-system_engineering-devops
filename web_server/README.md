# Web Server

This project covers the basics of web servers, DNS records, HTTP request-response cycles, and automating server provisioning on Ubuntu using Bash scripts and Nginx.

## Tasks

- **0-transfer_file**: Bash script that transfers a file from a client to an Ubuntu server via SCP.
- **1-install_nginx_web_server**: Automated installation and configuration of Nginx listening on port 80.
- **2-setup_a_domain_name**: Configuration of a .tech domain name with A record pointing to web-01.
- **3-redirection**: Configures Nginx with a 301 redirect for `/redirect_me`.
- **4-not_found_page_404**: Configures a custom 404 error page returning `Ceci n'est pas une page`.
- **5-design_a_beautiful_404_page.html**: Custom designed 404 error page.
